# 수간호사 청취 cheat sheet

> 1페이지 체크리스트 — 현장 인터뷰 시 빠뜨리지 않을 항목만.
> 형식적 설문 대신, 자연스러운 대화 중 메모하기 위한 가이드.
>
> **각 항목은 `docs/rules/scheduling-rules.md`의 룰 ID와 연결됩니다** (괄호 참조).
> 답변을 받아오면 해당 룰의 `Status: pending → confirmed`로 승격하고 값을 채웁니다.

---

## A. 시프트 정의 (확정용)

- [ ] D / E / N 시작·종료 시각, 인계 시간 *(G-01)*
- [ ] "Off" 외에 따로 쓰는 코드 있는지 (Edu, V, S, H 등) *(G-03)*
- [ ] 야간 전담(N-only 인력) 운영 여부 *(G 후보)*

## B. 절대 안 되는 것 (hard constraint 후보)

- [ ] N 후 바로 D로 갈 수 있는지? 며칠 쉬어야 함? *(H-01, H-06)*
- [ ] N 연속 최대 며칠?  → ___일 *(H-02)*
- [ ] 연속 근무 최대 며칠? (Off 없이) → ___일 *(H-03)*
- [ ] 시프트별 최소 인원 (D / E / N) → ___ / ___ / ___ 명 *(H-04, ward_settings.min_*)*
- [ ] 신규(3개월 이내) 단독 N 금지인지? *(H-08?)*
- [ ] 절대 배정 안 하는 패턴 있는지? (예: E→D 같은 "역방향") *(H-07?, H-09?)*

## C. 되도록 피하기 (soft constraint 후보)

- [ ] N → Off → D 같은 짧은 휴식 패턴 허용? *(S-05)*
- [ ] 주말 근무를 사람마다 균형 맞춰야 하는지? 어느 정도까지 OK? *(S-03)*
- [ ] 월 Off 수는 사람마다 똑같이? 차이 허용?  → 차이 ___일까지 *(S-01, balance_off_tolerance)*
- [ ] 같은 시프트가 연속 며칠 이상이면 피로감 느낌? → D ___, E ___ 일 *(S-04)*
- [ ] 페어(특정 두 명 같이 / 따로) 운영하는지? *(S-06?, S-07?)*
- [ ] 시프트별로 시니어 1명 이상 같은 정책 있는지? *(S-09?)*

## D. 희망일·불가일 운영

- [ ] 한 사람이 월 몇 개까지 희망일 낼 수 있나? *(W-02, W-03)*
- [ ] 희망일 마감은 며칠 전? (전월 ___일) *(W-04)*
- [ ] "절대 불가(연차/경조사)"와 "되도록 피해주세요"를 구분해서 받는지? *(W-01)*
- [ ] 희망 충돌 시 우선순위 결정 방식 (선착순? 횟수? 직책?) *(W-06)*

## E. swap(교환) 운영

- [ ] 확정 후 변경은 보통 어떻게? (구두? 메신저? 양식?) *(X-01 컨텍스트)*
- [ ] 수간호사 승인 필수? 당사자 간 합의만으로 OK? *(X-01)*
- [ ] 며칠 전까지 swap 가능? *(X-04)*
- [ ] swap 후 규칙 위반 발생 시 어떻게 처리? *(X-03)*
- [ ] head_nurse가 합의 없이 강제로 바꾸는 경우 있는지? *(X-05)*

## F. 인원 변동 케이스

- [ ] 휴직/병가/연차 장기 발생 시 듀티 어떻게 다시 짜는지? *(R-01)*
- [ ] 신규 입사·휴직 복귀가 월 중간에 들어오면? *(R-02)*
- [ ] 임시 파견·외근 등 부분 출근일 다루는지? *(R 후보)*

## G. 가장 짜증 났던 케이스 (개방형 — 가장 중요)

- [ ] "이거 자동화돼 있으면 정말 좋겠다" 1순위
- [ ] "이건 절대 자동으로 하면 안 된다" 1순위
- [ ] 듀티표 확정 후 가장 자주 들어오는 컴플레인 유형
